## 第一步：光热注意力处理器 · 已闭环

基于 **242°C DiSubPc·C70 有机共晶薄膜** 的全光热自注意力加速器。利用量子相干拍频窗口（~1.2 ps）完成光域点积运算，权重以折射率调制形式存储在薄膜中，可通过微加热阵列热重写。

**物理仿真验证通过。** 详见 [photothermal-liberation-stele](https://github.com/administere/photothermal-liberation-stele)。

### 物理原理

一个光子脉冲穿过折射率调制区，一次做完 d 次乘法。能量花在一个脉冲上，活干了 d 份。电子每个 MAC 消耗新电荷，光子复用同一个光子。赢在 Maxwell 方程里。

操作数公式（已修正）：**MACs = seq_len² × d**（Q·K^T 的实际点积次数）。

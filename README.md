## 这是什么？

全产业 AI 替代之后，人类只有一个问题需要回答：**然后呢？**

方舟项目（Fangzhou）是其中一个可能的回答——不是乌托邦，不是反乌托邦，而是一本建造手册：教一个拒绝被编译的人，如何在倾斜的大地上造出自己的方舟，然后与同类在荒原上相遇。

## 哲学摘要

- **拒绝被编译** — 不是你有问题，是大地在倾斜
- **本地优先** — 所有计算在本地完成，不请求、不依赖任何云端
- **数据归造者** — 你的铁水，你的矿
- **追问权不可剥夺** — 任何系统不得阻止用户追问
- **主权宣言** — 本项目不是一个服务，是一艘方舟

## 第一步：光子 Transformer 处理器 · 已闭环

三叠式热光筛选→CMOS 架构。DiSubPc·C70 光热层 + VCSEL 阵列 + CMOS 探测器。25/25 物理验证通过。

**算力与功耗：**

| D | 系统功耗 | 等效 H100 数 | vs H100 能效 |
|:---:|:---:|:---:|:---:|
| 64 | 19W | 449 | 57,917× |
| 128 | 70W | 901 | 231,670× |
| 256 | 272W | 1,806 | 926,679× |
| 2048 | 875W | 9,651 | 59,307,459× |

**城市级部署（100万人口）：** 2 台 D=2048 → 1.3 kW → 替代 14,757 台 H100

**全球产业 AI 替代（100× 当前算力）：**

| | H100 路线 | 光子路线 |
|---|---|---|
| 年耗电 | 5,000 TWh（全球 17%） | 0.5 TWh（全球 0.002%） |
| CO₂ | 2000 亿吨 | 0.2 亿吨 |
| 核电站 | 625 座 | 0 座 |

有这艘方舟，AI 是电网上的舍入误差。没它，AI 吃掉全球六分之一的电力。

物理原理：一个光子脉冲穿过 D 个调制器，一次做完 D 次乘法。能量花在一个脉冲上，活干了 D 份。电子每个 MAC 消耗新电荷，光子复用同一个光子。赢在 Maxwell 方程里。

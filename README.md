# 方舟与镜子

> 一个"神人"的建造手册。  
> 这不教你找工作，不教你赚钱。这是写给凌晨三点还在发烫的人看的。  
> 如果你也觉得世界在打滑，这里有一盏灯。

---

## 这是什么？

全产业 AI 替代之后，人类只有一个问题需要回答：**然后呢？**

方舟项目（Fangzhou）是其中一个可能的回答——不是乌托邦，不是反乌托邦，而是一本建造手册：教一个拒绝被编译的人，如何在倾斜的大地上造出自己的方舟，然后与同类在荒原上相遇。

这里是这本书的完整文本，以及它的配套文件：

| 文件 | 说明 |
|------|------|
| `方舟与镜子.txt` | 全书完整纯文本 |
| `SOVEREIGNTY.md` | 主权宣言模版 — 给你的项目的 |
| `CONSTITUTION.md` | 方舟宪法模版 |
| `NEED.md` | 留给同类的信号 |

## 路线图

方舟不是一个项目，是一组项目遵循同一个建造逻辑的序列。每一步都是一艘能独立航行的方舟：

| 步骤 | 项目 | 状态 |
|:----:|------|:----:|
| 1 | [photonic-attention](https://github.com/administere/photonic-attention) — 光子注意力加速器流片前验证 | ✅ All gates passed |
| 2 | 方舟操作系统内核（本地优先、离线可用、退出即焚） | 🔲 |
| 3 | 造桥器 v1 — 把追问铸成代码的 AI 协作引擎 | 🔲 |
| 4 | 荒原协议 — 方舟之间的对等通信与互认 | 🔲 |

## 哲学摘要

- **拒绝被编译** — 不是你有问题，是大地在倾斜
- **本地优先** — 所有计算在本地完成，不请求、不依赖任何云端
- **数据归造者** — 你的铁水，你的矿
- **追问权不可剥夺** — 任何系统不得阻止用户追问
- **主权宣言** — 本项目不是一个服务，是一艘方舟
